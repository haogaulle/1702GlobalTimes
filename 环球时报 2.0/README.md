# 环球时报 2.0

`index.html` 是本版本首页，每页展示十条完整博文。首页读取 `posts.json`，先按 `order` 数值升序排序，再加载当页独立 HTML 中的 `<main>` 下的 `<article>`，直接插入页面。正文仅保存在各篇 HTML 中，不在首页重复维护。博文正文直接展示内容，不额外添加标题。

新增博文：

1. 参考 `广告.html` 创建完整、可独立阅读的 HTML，保留当前版式和内联样式。博文放在本目录，与首页同级；图片统一存入 `static/` 文件夹，并使用 `./static/文件名` 相对路径引用；文字原稿保留在 `原稿/`。
2. 将完整正文放入一个 `<article>`，包含账号信息、正文和附件，直接展示原稿内容，不额外添加博文标题；使用 `aria-label` 描述文章。
3. 在 `posts.json` 中加入 `{"file": "新博文.html", "title": "新博文", "order": 0}`。`order` 使用数字，数值越小越靠前；相同值按清单中的原始顺序展示，未填写或不是有效数字时排在末尾。调整 `order` 即可改变首页顺序，无需移动清单条目。文件名含 `?`、`#` 等 URL 特殊字符时，`file` 应填写经过 URL 编码的相对路径。
4. 首页自动计算页数；可用 `index.html?page=2` 直达第二页。新增内容模块时同步维护首页与独立博文的对应内联样式。

通过 GitHub Pages 或本地 HTTP 服务访问首页（例如在仓库根目录运行 `python3 -m http.server 8000`）。浏览器通常禁止以 `file://` 读取其他本地文件，因此双击本地首页无法加载信息流；独立博文仍可直接打开。不需要安装依赖或构建。
